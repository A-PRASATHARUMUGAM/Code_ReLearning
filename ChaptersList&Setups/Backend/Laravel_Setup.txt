--- 2. Configure MySQL  ---


- Create a database:

CREATE DATABASE student_api;

- Open .env:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=student_api
DB_USERNAME=root
DB_PASSWORD=



--- 3. Create Model + Migration ---

- Run 
    php artisan make:model Student -m


- This Create
app/Models/Student.php
database/migrations/xxxx_create_students_table.php


- Open the migrations
- Create 

Schema::create('students', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('email')->unique();
    $table->integer('age');
    $table->string('course');
    $table->timestamps();
});

- Then Run 
    php artisan migrate
